# Linear Algebra Playground

Interactive companion for a series of articles based on 3Blue1Brown's *Essence of Linear Algebra*. Plot vectors, add and scale them, take products, and watch matrices transform space — in 2D or 3D.

## Run

```bash
npm install
npm run dev
```

Then open [http://localhost:4321](http://localhost:4321).

```bash
npm run build    # static output in dist/
npm run preview  # serve the production build
```

Astro, React, shadcn/ui, the VengeanceUI pop-button, Three.js for 3D, and the Canvas API for 2D.
